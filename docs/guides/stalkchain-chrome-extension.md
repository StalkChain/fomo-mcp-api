# StalkChain Chrome extension for DEX Screener and GMGN

Use the StalkChain Chrome extension to see token holders, early buyers, and public wallet activity next to the crypto page you already have open. The extension supports sites including DEX Screener, GMGN, FOMO and Pump.fun.

## Install from the Chrome Web Store

1. Open [StalkChain in the Chrome Web Store](https://chromewebstore.google.com/detail/stalkchain-ai-for-crypto/ojkkdeffdgbnainnkcoicogikfhpenng), select **Add to Chrome**, and review the browser permission prompt.
2. Open a supported token page in Chrome. Choose the StalkChain icon in Chrome’s **Extensions** menu to open the side panel. Pin it to the toolbar if you want quicker access.
3. If the panel asks you to connect, sign in to StalkChain and review the authorization prompt. Some queries use account credits.

## Check holders on a token page

Open a token page on DEX Screener or GMGN, then look for the holders and early-buyers views in StalkChain. Match the token address and chain to the page before comparing wallets. Holder lists and wallet activity describe public blockchain data and can change over time.

StalkChain’s extension is read-only and cannot sign or place trades. For help with sign-in, permissions or data handling, see the [extension privacy policy](https://data.stalkchain.com/privacy/extension) or contact [StalkChain support](mailto:support@stalkchain.com).

To run similar lookups in an AI assistant, use the [hosted StalkChain MCP](../../README.md#quick-start-mcp) and the [Solana wallet research guide](solana-wallet-tracker-mcp.md).
